# Little Haven — MVP v0.3

브라우저에서 실행하는 생활형 펫 수집·교배 시뮬레이션의 첫 번째 플레이 가능 프로토타입입니다.

## 실행 방법

1. ZIP 압축을 풉니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다.
3. 마을 화면에서 펫을 클릭하거나 오른쪽 메뉴를 사용합니다.
4. 저장 데이터는 현재 브라우저의 `localStorage`에 자동 보관됩니다.

별도의 Node.js 설치, 서버 실행, API 키가 필요하지 않습니다.

## 포함된 기능

- 탑다운 초원 마을 화면(픽셀아트)과 펫 동작(걸을 때 통통 튀기, 쉴 때 숨쉬기)
- 시작 펫 2종, 초원 종족 6종 + 숲 종족 9종(특정 부모 조합 전용 2종, 속성이 두 개인 복합 속성 3종 포함). 종족 이름은 모두 임시
- 펫 선택(특성 효과·잘하는 일 표시), 작업장 배치, 먹이 주기, 놓아주기
- 교감: 쓰다듬기, 놀아주기(연출만 있고 친밀도 같은 수치는 없음), 펫 이름 바꾸기(이름을 바꾼 펫은 종족 이름을 함께 표시)
- 마을 그림에서 시설을 누르면 시설 정보와 배치된 펫 표시
- 농장·벌목장·채굴장·제련소 건설과 자동 자원 생산
- 격자 자유 배치: 건설하기를 누른 뒤 마을 그림에서 원하는 칸을 눌러 짓기(초록 = 놓을 수 있음, 빨강 = 겹침, Esc = 취소), 지은 시설은 '옮기기'로 다른 칸에 옮기기(무료)
- 생산 시설 업그레이드(최대 Lv.3, 레벨만큼 생산량 증가)
- 지역 개방: 안개에 가려진 숲을 조건 달성 후 자원으로 개방. 개방하면 끼고미 1마리가 합류하고 숲 종족이 교배로 태어나기 시작함
- 종족 도감(지역별 묶음, 종족별 희귀 외형 기록)
- 도트 그림(AI 이미지 생성 후 진한 외곽선·쨍한 색으로 다듬음, 마을에는 2배 크기로 표시): 펫 15종, 시설 6종, 나무·덤불·꽃·바위·알, 자원 아이콘 4종. 마을 화면과 오른쪽 메뉴(펫 목록, 펫 정보, 도감, 시설 카드, 알, 상단 자원)에 표시. 풀밭은 코드로 그린 짙은 초록 픽셀 배경(흙길 없음). 희귀 외형 펫은 무늬(줄무늬·물방울·반짝임)가 보임
- 부모 펫 2마리를 선택하는 교배 및 알 부화(부모 목록에 속성·특성·에너지 표시)
- 종족 도감과 희귀 외형 발견 기록
- 자동 저장 및 최대 24시간 오프라인 진행 계산(복귀 시 얻은 자원 요약)
- PC 및 모바일 화면 크기에 대응하는 기본 레이아웃

## 테스트용 밸런스 값

`game.js` 상단의 `CONFIG`, `ELEMENTS`, `RARITIES`, `SPECIES`, `LEGACY_SPECIES_NAMES`, `TRAITS`, `BUILDING_TYPES`, `REGIONS`, `BREEDING_RULES`에서 조정할 수 있습니다. 밸런스 숫자는 모두 이 구역에 모여 있습니다.

- 자원 생산 기준 주기: 60초
- 펫 작업 에너지 소모: 작업 1분당 2
- 휴식 에너지 회복: 1분당 2
- 작업 중단 기준: 최대 에너지의 25% 이하 / 재개 기준: 90%까지 회복
- 교배 에너지 소모: 부모 각각 20
- 알 부화 시간: 180초
- 오프라인 진행 상한: 24시간
- 펫 보유 한도: 30마리
- 작업장 배치 한도: 시설당 2마리
- 조합 전용 종족: 슬달이 + 산들우 → 아슴이 약 20%, 몽양이 + 끼고미 → 나북이 약 20% (숲 개방 후에만)
- 미발견 종족 발견 보정(개방한 지역의 종족만, 조합 전용 제외): 교배 1회당 18% 발견 추첨 (호기심 부모 1마리당 +6%p, 일반 종족이 희귀 종족보다 먼저 나오기 쉬움)
- 적성 보너스: 시설과 속성이 맞으면 생산량 ×1.35 (농장: 풀·물 / 채굴장: 땅 / 벌목장: 땅·바람 / 제련소: 불·전기)
- 먹이 주기: 식물 3 → 에너지 +25
- 시설 업그레이드: 최대 Lv.3, 비용은 건설 비용의 2배(Lv.2)·4배(Lv.3), 생산량 ×레벨 (채굴장의 광석 부산물 포함, 에너지 소모는 그대로)
- 숲 개방 조건: 마을 3단계 + 발견 종족 5종 + 목재 100·돌 60 소모
- 복합 속성 종족(숲 개방 후에만, 각 약 17%): 풀 + 물 → 연구리, 불 + 전기 → 화르비, 땅 + 바람 → 모래찌. 작업 적성은 두 속성 중 하나만 맞아도 적용
- 놀아주기: 에너지 5 소모, 자유 생활 중인 펫만 가능
- 마을 단계 기준 점수(시설 수 + 발견 종족 수 × 2): 2단계 8, 3단계 13, 4단계 36(모든 시설 + 전체 15종)

위 수치는 최종 밸런스가 아니라 빠른 기능 검증용 임시 값입니다.

검증 상세는 `TEST_RESULTS.md`, 기획 대비 구현 현황과 v0.2 수정 내역은 `IMPLEMENTATION_STATUS.md`를 참고하세요.

## 알려진 제한 사항

- 지역은 초원과 숲 두 곳뿐이고, 숲은 마을 그림에는 나타나지 않습니다(목록과 도감에만 표시).
- 희귀 외형 무늬는 마을 화면에만 보이고, 오른쪽 메뉴에서는 이름 옆 ✦ 표시뿐입니다. 종족별 기록은 이번 버전부터 쌓이며, 예전 저장은 지금 데리고 있는 펫의 외형만 반영됩니다.
- 건물 철거, 창고 한도는 미구현입니다. 건물은 모두 같은 크기(3×2칸)입니다.
- 밸런스 수치는 직접 플레이한 느낌을 반영한 조정을 아직 하지 않았습니다(마을 4단계 기준만 종족 수에 맞춰 고침).
- 같은 게임을 탭 두 개에서 동시에 열면 나중에 저장한 쪽이 덮어씁니다.
- 펫 간 사회적 관계, 복잡한 행동 트리, 전투, 멀티플레이, 서버 동기화는 제외했습니다.
- 글자 사이에 들어가는 작은 기호(비용의 🪵, 버튼의 ⚡, 속성의 💧 등)와 💤·💗·🎵 같은 연출 기호는 이모지입니다. 펫 걷기는 그림 한 장을 튀게 하는 방식이라 다리가 움직이지는 않습니다.
- 브라우저 저장은 해당 브라우저·기기에 종속되며 다른 기기와 동기화되지 않습니다.

## 저장 데이터 초기화

게임 화면 하단의 `초기화`를 누르면 현재 브라우저의 Little Haven 저장 데이터가 삭제됩니다.

## 파일 구성

- `index.html`: 게임 화면 구조
- `style.css`: 레이아웃과 시각 디자인
- `game.js`: 게임 규칙, 데이터, 저장, 렌더링
- `assets/pets/`: 펫 그림 15장(28×28 투명 PNG, 파일 이름은 종족 ID, 화면에는 2배). 이 폴더가 없어도 게임은 임시 그림으로 실행됩니다
- `assets/buildings/`: 시설 그림 6장(60×50 투명 PNG, 파일 이름은 시설 ID, 화면에는 2배)
- `assets/decor/`: 나무·소나무(32), 덤불(22), 꽃·바위(18), 알(12) 그림(투명 PNG, 화면에는 2배)
- `assets/resources/`: 자원 아이콘 4장(24×24 투명 PNG, 파일 이름은 자원 ID)
- `tools/slice_sprites.py`: 여러 펫이나 시설을 한 장에 그린 그림을 하나씩 파일로 잘라 내는 도구(게임 실행에는 필요 없음)
- `tools/bold_pixels.py`: 잘라 낸 그림을 진한 외곽선·쨍한 색·적은 색 수로 다듬는 도구(게임 실행에는 필요 없음)
- `tools/build_single_html.py`: 게임 전체(그림 포함)를 HTML 파일 하나(`little-haven-single.html`)로 묶는 도구(게임 실행에는 필요 없음)
- `IMPLEMENTATION_STATUS.md`: 기획 대비 구현 현황, 수정 내역, 다음 단계 제안
- `TEST_RESULTS.md`: 검증 결과
- `tests/regression.js`: 자동 검사 코드(게임 실행에는 필요 없음)
- `DEVELOPMENT_GUIDE.md`: PC에서 Claude Code로 이어서 개발하는 단계별 길라잡이
- `CLAUDE.md`: Claude Code가 자동으로 읽는 프로젝트 작업 규칙
- `AGENTS.md`: GPT·Codex 같은 다른 AI 도구용 작업 규칙(`CLAUDE.md`와 같은 내용)
- `HANDOFF.md`: 다른 AI로 작업을 이어 갈 때 읽는 인계 문서(지금까지 한 일, 코드 구조, 남은 일, 주의할 점)
